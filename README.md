## 📖 Sobre

Projeto acadêmico de **modelagem e implementação de um banco de dados** para uma plataforma de cursos digitais, inspirada em serviços como Udemy e Coursera.

O sistema irá contemplar:

* Usuários com perfis de **aluno e/ou professor**, utilizando especialização EER;
* Cursos, módulos e **pré-requisitos**;
* Matrículas, acompanhamento de **progresso e certificados**;
* Campanhas promocionais e **cupons de desconto** com histórico temporal;
* Fórum de dúvidas envolvendo **alunos, professores e módulos**.

## 🛠️ Tecnologias

* **Modelagem:** EER, Modelo Relacional, diagrams.net / PlantUML
* **SGBD:** Oracle Database (Oracle Live SQL)
* **Linguagem:** SQL e PL/SQL
